03 · worker updates

The daemon installs GitHub releases of Identity-md/worker. With auto-update on it checks every five minutes and installs while idle; off, you update from here. A rollback installs an older release with npm and turns auto-update off, otherwise the daemon would reinstall the latest within minutes.
